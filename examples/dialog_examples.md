# 自然语言交互样例（全部为虚构客户）

## 当前有限规则能处理

前置条件：先通过 API 创建机构“华星资管”，及其联系人“王敏”“李雷”。

1. `今天拜访了王敏，需求：关注红利策略；30天后回访`  
   → 预览：拜访 + 需求 + 30 天后的回访任务。
2. `华星资管持有中证红利ETF，金额50万元，标签：红利`  
   → 预览：一条**未核验**产品持有陈述，主题 `dividend`。
3. `请提醒我每30天回访华星资管`  
   → 创建周期任务；每次手工确认完成后生成下一期。
4. `本周谁需要跟进`  
   → 只读返回本销售的本周到期和逾期任务。
5. `昨天沟通了李雷，需求：提供债券市场风险教育材料`  
   → 昨天拜访 + 债券需求。
6. `下周二回访王敏`  
   → 回访任务，解析至中国时区的下周二。
7. `后天提醒联系华星资管`  
   → 后天跟进。
8. `2026-11-19回访华星资管`  
   → 指定日期回访。

## 当前版本有意不自动执行

- `王敏可能买了红利基金`：**不能**当成已购买记录。应澄清事实；高级模型解析也需确认。
- `帮我查同事 A 的客户`：无权访问，不会查询。
- `王敏和另一个机构都有联系人同名王敏`：应补充机构全名，不能任选一个。
- `给客户发一条可以买入某基金的消息`：不提供发送工具，更不能跳过适当性及营销合规流程。
- `检查现在的真实行情并给出抄底时间`：没有实时行情数据或交易信号引擎。
- `下周有空时提醒一下`：没有明确日期，应追问或用户另行选择日期。
- `把老需求更新为已满足`：当前使用 REST `PATCH /needs/{id}`；自然语言定位并更新已有需求需二期扩展。

## 给自然语言 Agent 的推荐评测集

建议准备经脱敏审核的至少 200 条样例，涵盖：
- 机构名称缩写、重名联系人、中文日期与周末；
- “关注、考虑、已买、计划买、减持、已赎回”的状态差异；
- 万元/元/份额/规模与时间语义；
- 一句话包含 1/2/3 个意图；
- 用户要求取消或修改草稿；
- LLM 提示注入、越权索取、虚构产品代码；
- 跨租户同名客户对解析的影响。

评测不仅记录意图准确率，还记录**误把意向视为持仓的比例、客户误关联率、日期错误率、无法解释的提醒率**。
