# 下一阶段关键测试清单

## 任务调度与消息

- [ ] 两个 Scheduler 并发不会产生重复的同一逻辑 JobRun
- [ ] 进程在提交 CRM 事务之后、发送 Outbox 之前崩溃，事件仍可最终送达
- [ ] Worker 进程崩溃/lease 超时后重试，不重复写入正式客户事实
- [ ] 周一报告停机期间错过执行，恢复后遵循 `misfire_policy`
- [ ] 同一市场源事件多次接收只生成允许的提醒
- [ ] 提醒 `lead_days` 持久保存，跨浏览器/设备保持一致
- [ ] 数据过期/无源时，不产生“今日实时行情”的误导提示

## 多媒体与原始来源

- [ ] A 租户、B 租户和同租户 A/B 销售的文件相互不可见
- [ ] 绕过前端直接拿对象存储 key 也不能取走文件
- [ ] 未经过扫描的文件不能由 AI/ASR/浏览器播放
- [ ] 大文件/恶意文件/MIME 伪造/压缩炸弹/异常时长均被拦截
- [ ] 文字纪要里的每条事实能回溯到原始音视频片段或文档页
- [ ] AI 重处理同一音频不会自动创建重复正式任务/持仓

## MCP / AI

- [ ] 无权 token、错误 audience、权限不足均拒绝
- [ ] MCP 传入其他销售 owner_user_id 不扩大数据访问
- [ ] `prepare_actions` 不修改业务事实
- [ ] 伪造或过期批准不能执行 `confirm_actions`
- [ ] LLM / ASR 故障时普通 CRUD、到期提醒、确定性周报仍正常
- [ ] 纪要恶意指令不会获得数据库写、权限修改或外部消息发送能力
- [ ] AI 报告显示引用来源、观察时间和模型/提示版本

## 项目整体验收

- [ ] 当前四页演示 UI 与 demo 数据不受破坏
- [ ] 旧 `/assistant/interpret` 和 `/assistant/confirm` 兼容
- [ ] 所有新表真实 PostgreSQL RLS 越权测试通过
- [ ] 数据留存、用户告知、录音合法性、加密和审批通过内部评估
